# 摸鱼鼓励师 · Slack-Off Coach

一个 DeepSeek Harness Web UI 插件：在会话标题栏右上角实时显示「今日已入账」工资，金额每秒增长，并附带进度、距下班时间和摸鱼鼓励语。

```text
(¥) 今日已入账 ¥56.82
    摸鱼中 · 每秒 +¥0.0158
```

## 功能

- 右上角常驻胶囊，实时显示今日已入账金额
- 点击展开设置面板，输入月薪、每月工作天数、每天工作小时和上班时间
- 自动计算日薪、时薪、每秒工资
- 显示今日进度、距下班时间、今日状态
- 根据进度显示不同的摸鱼鼓励语
- 支持中英文界面
- 设置保存在本机浏览器 `localStorage`，不上传任何数据

## 计算方式

```text
日薪   = 月薪 ÷ 每月工作天数
时薪   = 日薪 ÷ 每天工作小时
每秒   = 时薪 ÷ 3600
今日已入账 = 每秒工资 × 今日已工作秒数
```

当前版本按 **周一至周五** 估算，只在「上班时间」到「下班时间」之间累计。下班时累计到完整日薪，周末显示休息日。上班时间默认 `09:00`，可在设置中修改。

## 安装

这是一个 DSH bundle，仓库根目录就是插件包目录。

1. 克隆本仓库到本地。
2. 在 DSH 的插件管理中使用「本地目录 / 本地路径」安装该目录，或通过 Plugin Manager 的 `install_bundle` 指向仓库根目录。
3. 打开任意会话，右上角会出现「摸鱼鼓励师」。
4. 点击胶囊，填入月薪等信息并保存。

插件清单见 [`package.json`](./package.json)，bundle patch 见 [`cordis.patch.yml`](./cordis.patch.yml)。

## 开发

- `client.js`：Web UI 组件、计时器、计算逻辑、样式和嵌入的语言字典
- `index.js`：Host 半部分（当前为空）
- `locale/*.json`：插件管理页显示用的标题与描述
- `icon.svg`：插件图标

修改 `client.js` 后，重新加载 DSH 页面或重启应用即可看到新版本。

## 已知限制

- 按周一至周五估算，暂不支持自定义工作日
- 暂不支持午休扣除
- 收入按当前时间与上班时间计算；关闭页面后重新打开，会按实际时间补上已过时段的金额
